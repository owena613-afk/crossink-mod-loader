How do I get an access token?
  1. On GitHub: your picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → crossink-mods-builder.
  3. Permissions: Actions: Read and write (everything else can stay at no access).
  4. Generate, copy it, and paste it above. It stays in this browser only and is sent only to GitHub.

No token? Use Open the GitHub form instead: it opens the same build form on GitHub, where you tick the same boxes.

Finished builds have a Download link to the build's page on GitHub; the firmware is under Artifacts. Download the zip, then put it on a reader with the Flash a reader (USB) tab.

1. Choose the firmware

Pick the zip you downloaded from a finished build (under Artifacts on its GitHub page), or a single .bin. A zip holds the X4 and X4 Pro firmware; the right one is picked for whichever reader you plug in.

    2. Connect and flash

    1. Plug the reader into this computer with a USB cable that carries data. It can be on any screen, or asleep.
    2. Press Connect reader and pick USB JTAG/serial debug unit (on some computers it's called USB Serial Device).
    3. Press Flash. It takes about a minute, then the reader restarts on its own.

    Only the firmware is replaced: your books, reading progress, sleep images and settings live on the SD card and aren't touched. The reader keeps its own firmware layout; this writes the slot it already starts from and checks every byte afterwards.

    Edit a reader's mod settings
    
      
    The reader keeps its mod settings in /.crosspoint/mods/settings.json on its SD card. Open that file (or start from the defaults), change what you like, save, and copy it back. The reader picks it up the next time it starts or wakes. Each reader has its own file, so you can set the two differently.
